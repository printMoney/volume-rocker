# Integration

- `AppIntents.swift`: Shortcuts and Siri actions, with entities for apps, output devices and profiles.
- `UpdateController`: Sparkle auto-updates (off until a signing key is configured).
- `LoginItem`: open at login via `SMAppService`.
- `AppServices`: gives App Intents access to the running model.
- `ControlCenterRequest`: notification names shared with the Control Center extension.
